Privacy Policy

Effective date: November 17, 2026

This is a public game testing library. It does not offer accounts, cloud saves, or cross-device save syncing. Individual games may behave differently from the library pages.

Information handled by the library

The library pages do not ask you to create an account or submit personal information, and they do not provide cloud saves. Like other websites, the web host may receive technical request information when a page or file is requested, such as an IP address, requested URL, browser details, and time of request. The hosting provider, its logging practices, and retention periods depend on the service used to publish the site; the project operator should update this notice if those details become known or change.

Vercel Web Analytics

When this site is deployed to a Vercel project with Web Analytics enabled, it uses Vercel Web Analytics to count page views and report aggregated site usage. Vercel says this service does not use cookies or collect personal identifiers for cross-site tracking. Analytics data may include the page URL, referrer, timestamp, and general device, browser, operating system, and geographic information. Vercel uses a short-lived request hash for visitor counts that expires after 24 hours. See Vercel’s Web Analytics privacy details. The analytics script is not loaded from local files or localhost development sessions.

Game data on your device

Games may use browser storage, including local storage, to keep a score, settings, or progress on the device and browser where you play. This is not sent to a GiveGigsGames cloud save service. It may be removed by clearing browser data, using private browsing, changing browsers or devices, or by a game update. Games can also use browser features such as cookies or other storage; check the game’s behavior and notices.

Game-specific and third-party connections

A game may make network requests for features such as online play, APIs, fonts, libraries, or other content. The library includes games at different stages, so these connections vary by title. When a request goes to another provider, that provider may receive technical information such as your IP address and browser request details and handles it under its own privacy policy. Some catalog entries link to games hosted outside this site; their operators’ policies apply there.

Offline copies

You can download the repository and open its index page locally. When a game runs offline, requests that need the internet may not work. Any local browser storage remains subject to the browser and device you are using.

Children and sensitive information

This testing library is not designed to collect personal details. Do not enter sensitive or confidential information into a game or a third-party feature.

Updates and contact

This policy may be revised as hosting and game features change. The effective date above indicates when this page was most recently revised. Questions or privacy requests: Matt@MattyJacks.com.
